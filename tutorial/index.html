Getting started with your server

From checkout to your first login — here's everything you need to get a Minecraft server running on Angkor Hosting in a few minutes.

01

Choose a plan

Head to the Minecraft plans page and pick a tier based on your player count and mod list. As a rough guide:

  • 1–4 players, vanilla or light plugins — 1–2GB RAM
  • 5–15 players, plugin survival or SMP — 4–6GB RAM
  • Modded (Forge/Fabric) or 15+ players — 8GB+ RAM

You can always upgrade later without losing your world data.

02

Complete checkout

Select your billing cycle and complete payment. Your server is provisioned automatically — you'll receive a confirmation email with a link to your control panel within a couple of minutes.

03

Log in to the control panel

Use the credentials from your confirmation email to log in. From the dashboard, click your server to open its management page — you'll see console output, resource usage, and file access.

04

Pick your version and server type

Open the Startup tab and choose your Minecraft version and server jar — Vanilla, Paper, Spigot, Forge, or Fabric. Paper is recommended for most survival and plugin servers since it's optimized for performance.

05

Start the server

Hit Start from the console tab. The first boot downloads the server jar and generates your world, so it may take a minute or two longer than future restarts. Watch the console for Done! to know it's ready.

06

Connect and invite players

Copy your server's IP address from the panel overview and share it with your friends. In Minecraft, go to Multiplayer → Add Server and paste the address to connect.

07

Install plugins or mods (optional)

Use the File Manager to upload .jar plugin files into the plugins folder (Paper/Spigot) or mods folder (Forge/Fabric), then restart the server for them to load.

08

Set up backups

Open the Backups tab and create a manual backup, or schedule automatic ones. We recommend backing up before any major plugin or version change.

Common questions

Can I switch plans later?

Yes — you can upgrade or downgrade your plan at any time from your account dashboard. Your world files and configuration carry over automatically.

How do I change my server's difficulty or game mode?

Open the File Manager, edit server.properties, and update the difficulty or gamemode values, then restart the server for changes to take effect.

My server won't start — what should I check first?

Check the console for the error message, confirm your selected Minecraft version matches your server jar, and make sure any recently added plugins or mods are compatible with your server version.

Can I run a custom modpack?

Yes — select Forge or Fabric as your server type, then upload your modpack's server files through the File Manager, or use the panel's modpack installer if your plan supports it.
